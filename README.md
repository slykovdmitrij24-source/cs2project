# CS:GO Case Battle Simulator 🎮

Симулятор открытия кейсов, апгрейда предметов и битв в стиле CS:GO.

## 🎯 Возможности
- Открытие кейсов с разной редкостью
- Система апгрейда предметов (3 в 1)
- Битва предметами с противником
- Инвентарь для хранения скинов

## 🚀 Как играть
1. Открывай кейсы и собирай предметы
2. Объединяй 3 предмета для апгрейда (40% шанс)
3. Участвуй в битвах, выставляя 4 предмета
4. Побеждай и увеличивай баланс!
